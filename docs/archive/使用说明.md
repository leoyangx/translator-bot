# 韩语翻译机器人 · 使用说明

## 一、第一次使用

1. 双击 **安装依赖.bat**（只需要一次，装完可以删掉这个文件）
2. 双击 **启动.bat**
3. 双击 **开机自启.bat**（推荐，以后开机就自动跑）

在 Telegram 里搜索 `@kr_unnie_bot`，点 Start，发一句话就行。

> 第一次给它发消息的人会自动成为「主人」，之后别人发消息会被拒绝。
> 换人用的话，删掉 `data\bot.db` 再重新 /start。

## 二、怎么用

| 你做什么 | 它做什么 |
|---|---|
| 转发一条韩语消息给它 | 原文 + 中文译文，带按钮 |
| 直接粘贴韩语文字 | 自动识别是韩语，译成中文 |
| 发中文 | 译成韩语（默认敬语，可直接复制给对方） |
| 在群里回复某条消息并 @它 | 只翻那一条 |
| 点「更正式 / 更口语 / 直译」 | 换语气重译，不额外收费（同句有缓存） |
| 点「解释一下」 | 讲语法、敬语等级、ㅋㅋ 这类缩写 |

## 三、命令

| 命令 | 作用 |
|---|---|
| `/start` | 开始 |
| `/help` | 用法说明 |
| `/tone natural\|formal\|casual\|literal` | 改默认语气 |
| `/glossary` | 看术语表 |
| `/glossary add 김치 = 泡菜` | 加术语，以后固定译法 |
| `/glossary del 김치` | 删术语 |
| `/stats` | 今日调用次数和 token |
| `/doctor` | 自检：Telegram、模型、数据库 |
| `/id` | 看自己的 Telegram ID |

## 四、改配置

打开 `config.yaml`，改完保存，然后 **停止.bat → 启动.bat**。

常用项：

- `llm.model`：换模型（当前 `deepseek-v4-pro`，便宜的可用 `deepseek-flash`）
- `llm.api_key`：换 Key
- `proxy`：需要代理时填，例如 `http://127.0.0.1:10808`；直连留空
- `translation.default_tone`：默认语气

## 五、出问题了

1. 先发 `/doctor`，它会告诉你哪一环坏了
2. 看 `logs\bot.log` 最后几十行
3. 常见情况：

| 现象 | 原因 | 处理 |
|---|---|---|
| 发了没反应 | 程序没启动 | 双击 启动.bat，再发 /doctor |
| 提示「未授权」 | 你不是主人 | 删 `data\bot.db` 重新 /start |
| 提示 Key 无效 | Key 过期/写错 | 改 config.yaml |
| 提示余额不足 | 账户没钱 | 去 DeepSeek 充值 |
| 连不上 Telegram | 网络问题 | 在 config.yaml 里填代理 |

## 六、文件说明

```
翻译机器人\
├─ app\              程序源码（不用动）
├─ config.yaml       配置（Token、Key、代理）
├─ 启动.bat          启动
├─ 停止.bat          停止
├─ 开机自启.bat      设置开机自动运行
├─ 取消开机自启.bat  取消
├─ logs\             日志
└─ data\             数据库（缓存、术语表、用量）
```

备份就复制整个文件夹，或者只复制 `data\bot.db`。
